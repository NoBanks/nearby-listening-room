# Nearby Listening Room

A seated, hands-only listening room for Meta Quest. Reach out, pinch a record off the shelf, set it on the turntable, and the room comes up around the music of NoBanks Nearby.

Built for the Meta VR Start Developer Competition 2026 (Entertainment, New Experience) with the Immersive Web SDK.

## How it works

- **Hands first.** Pinch a record within reach and carry it to the platter, or pinch from a distance with a hand ray. No controller needed.
- **Teaches without text.** The room opens dark with one glowing record and two fingertips showing the pinch.
- **Real stereo in space.** Left and right come from the two speakers in the room, so the mix keeps its width and the sound stage stays put as you turn your head.
- **Fits any seat.** The room places itself around your head when the session starts.

## Run it

```
npm install
npm run dev
```

Node 20.19 or newer. Without a headset, IWER (the emulator built into IWSDK) simulates one in the browser.
